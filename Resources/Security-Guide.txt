Window Switcher — First Launch & Security Note
==================================================

Thank you for downloading Window Switcher!

Window Switcher is 100% open-source, private, and runs entirely on your Mac.
All window rendering and keyboard navigation stay strictly local.

--------------------------------------------------
INSTALLATION:
--------------------------------------------------
1. Drag "WindowSwitcher.app" into your "Applications" folder.
2. Launch WindowSwitcher from Applications.

--------------------------------------------------
FIRST-TIME MACOS GATEKEEPER NOTE:
--------------------------------------------------
Because Window Switcher is an independent open-source project distributed
directly from GitHub, macOS Gatekeeper may show a notice on first launch:
"Apple cannot check it for malicious software" or "unidentified developer".

This is standard macOS security for all software downloaded outside the
Mac App Store. You only need to approve it ONCE:

▸ Option 1 — System Settings (Standard GUI):
  1. Open System Settings.
  2. Navigate to "Privacy & Security".
  3. Scroll down to the "Security" section.
  4. Next to the message about WindowSwitcher, click "Open Anyway".

▸ Option 2 — Terminal (Instant 1-Click Fix):
  Open Terminal and run:
  xattr -cr /Applications/WindowSwitcher.app

Once approved, macOS remembers your authorization forever.
